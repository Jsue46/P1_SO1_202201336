# MANUAL DE USUARIO  
**Proyecto 1 – Sistemas Operativos 1**

---

## 1. Introducción

Este manual describe el uso del sistema de monitoreo de recursos implementado para el Proyecto 1 de Sistemas Operativos 1. El sistema permite visualizar el consumo de recursos del sistema y de contenedores Docker en tiempo real mediante un dashboard en Grafana.

El usuario no interactúa directamente con el kernel ni con el daemon; toda la interacción se realiza a través de la interfaz gráfica de Grafana.

---

## 2. Requisitos para el usuario

Para utilizar el sistema, el usuario debe contar con:

- Navegador web moderno (Chrome, Firefox, Edge)
- Acceso al servicio de Grafana
- El sistema en ejecución (módulos del kernel y daemon activos)

No se requieren conocimientos de programación para interpretar la información mostrada.
